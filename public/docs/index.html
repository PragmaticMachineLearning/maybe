Overview

Alea combines spreadsheet familiarity with Monte Carlo simulation. Enter uncertainty as confidence intervals, reference them in formulas, and visualize the resulting distributions—all without custom scripts.

For New Users

Guided examples for entering confidence intervals and interpreting distribution plots.

For Advanced Users

Understand how GaussFormula powers sampling and chains uncertain values through formulas.

Built on GaussFormula, a fork of HyperFormula with native support for uncertainty. Alea adds an intuitive confidence interval interface on top of the engine's probabilistic capabilities.

Architecture

Alea is a React application wrapping GaussFormula with ergonomics for uncertain inputs.

State Management

SpreadsheetProvider instantiates GaussFormula with 10,000 samples per distribution. It exposes helpers to update cells, read formulas, and manage distribution view preferences.

Types like ConfidenceIntervalNumber and SampledDistribution encapsulate uncertainty state and provide sampling utilities.

Sampling Technique

Every uncertain value becomes 10,000 samples before arithmetic. GaussFormula performs operations element-wise and returns a new sampled distribution.

Confidence Intervals

Call toSamples() with generators for normal, lognormal, or uniform distributions.

Derived Distributions

Sums, products, and other operations create SampledDistribution objects.

Helper Generators

Reusable sampling functions in InterpreterValue.ts.

Deterministic inputs bypass sampling. A formula referencing only numbers evaluates once. Mix in an uncertain cell, and GaussFormula switches to Monte Carlo mode.

Confidence Intervals

Cells accept shorthand notations converted to ConfidenceIntervalNumber instances:

CI[20, 50]

Explicit prefix, defaults to 95% confidence.

[20, 50]

Bracket-only shorthand.

20 to 50

Natural language range.

When bounds are positive and upper/lower > 2, Alea defaults to lognormal. Otherwise, it uses normal. Override via the cell's dropdown menu.

Creating Uncertainty Cells

  1. Enter a confidence interval

    Type CI[10, 25], [35, 55], or 20 to 50 in any cell.

  2. Confirm with Enter

    The cell displays a distribution icon and formatted summary like N(μ=…, σ=…).

  3. Choose interpretation

    Use the dropdown to switch between normal, lognormal, or uniform distributions.

  4. Reference in formulas

    Use the cell like any number. Downstream cells inherit sampled distributions automatically.

Advanced: Paste sampled results as S(μ=…, σ²=…) for direct SampledDistribution values.

Analysis Panel

Flow Diagram

Visualize dependencies between cells. Open via the toolbar's graph icon. The spreadsheet dims to focus on the dependency overlay.

What It Shows

  • Nodes — Cell addresses, values, types, and formulas.
  • Uncertain values — Distribution summaries like CI[a, b] or S(μ, σ²).
  • Edges — GaussFormula's dependency graph showing how uncertainty propagates.

Trace variance sources by following edges backward from volatile outputs. Pan, zoom, and navigate with @xyflow/react controls. Press Escape to return.
