Alea User Documentation

This guide introduces Alea’s probabilistic spreadsheet workflow. It explains how uncertainty values are parsed, sampled, and visualised so you can build models that quantify risk without leaving the grid.

Goals & Audience

Alea targets analysts who already understand spreadsheets and want to add quantitative uncertainty without writing bespoke Monte Carlo scripts. The documentation focuses on:

  • New users who need guided examples for entering confidence intervals and reading the charts.
  • Advanced users who want to understand how HyperFormula powers sampling and how outputs can be chained through formulas.
Alea uses the open-source HyperFormula engine. Any deterministic formula supported by HyperFormula works, and uncertainty-aware values fall back to deterministic behaviour when no ranges are present.

Architecture Overview

Alea is a React application that wraps HyperFormula with a set of ergonomics tailored to uncertain inputs.

Client components

  • Spreadsheet grid (src/components/Spreadsheet.tsx) renders the table UI and delegates edits to the context.
  • Cell renderer (src/components/CellRenderer.tsx) formats deterministic values, confidence intervals, and sampled distributions with icons and context menus.
  • Toolbar (src/components/Toolbar.tsx) toggles the Analysis panel, Flow Diagram, Examples, Theme, and now provides a Docs shortcut.
  • Analysis panel (src/components/AnalysisPanel.tsx) is a resizable aside that surfaces statistics and the distribution plot for the selected cell.
  • Flow diagram (src/components/FlowDiag.tsx) overlays a dependency graph built from HyperFormula’s internal graph.

State & engine integration

The SpreadsheetProvider (src/SpreadsheetContext.tsx) instantiates HyperFormula with a sample size of 10,000. It exposes helpers to update cells, read formulas, and store per-cell distribution view preferences. All dependent components subscribe to this context instead of reaching into HyperFormula directly.

HyperFormula types such as ConfidenceIntervalNumber and SampledDistribution (see hyperformula/src/interpreter/InterpreterValue.ts) encapsulate the uncertainty state and provide sampling utilities used throughout the UI.

Sampling Technique

Every uncertain value ultimately becomes a set of samples before arithmetic is performed. HyperFormula’s configuration sets sampleSize = 10000, so each CI input or sampled distribution produces 10,000 draws when used in formulas.

  • Confidence intervals call ConfidenceIntervalNumber.toSamples(), which selects a generator based on the interpretation (normal, lognormal, or uniform).
  • Derived distributions (e.g., sums or products) exist as SampledDistribution objects whose getSamples() output flows into the Analysis panel or other cells.
  • Helper generators (generateNormalSamples, generateLogNormalSamples, generateUniformSamples) live in InterpreterValue.ts and are reused consistently.

Sampling happens on demand: when a formula pulls in an uncertain operand, HyperFormula requests samples, performs the operation element-wise, and stores the result as another sampled distribution.

Deterministic inputs bypass sampling entirely. A formula that references only classical numbers is evaluated once; the moment an uncertainty cell participates, the engine switches to Monte Carlo execution for that branch.

Confidence Interval Input

Cells accept shorthand notations that the parser recognises and converts into ConfidenceIntervalNumber instances (hyperformula/src/CellContentParser.ts):

  • CI[20, 50] — explicit prefix, defaults to a 95% CI.
  • [20, 50] — bracket-only shortcut.
  • 20 to 50 — natural-language range.

Bounds can be negative or positive. When both are positive and the ratio upper/lower exceeds roughly 2×, Alea automatically interprets the range as lognormal; otherwise it defaults to a normal interpretation. You can override the interpretation later from the Analysis panel’s view menu.

Creating Uncertainty Cells

  1. Select a cell and type one of the supported notations (CI[10, 25], 35 to 55, etc.).
  2. Confirm with Enter. The cell renderer shows a distribution icon and a formatted summary (N(μ=…), LN(μ=…), or U[…]).
  3. Use the cell’s dropdown to switch between normal, lognormal, and uniform interpretations if needed.
  4. Reference the cell in formulas exactly as you would with deterministic numbers; downstream cells will inherit sampled distributions.

Advanced users can also paste sampled results in S(μ=..., σ²=...) form, which the parser recognises as SampledDistribution values ready for further computation.

Using the Analysis Panel

Activate the panel with the toolbar’s Analysis button or by right-clicking a distribution cell and choosing “Analysis”. The panel docks to the right and can be resized horizontally.

What you’ll see

  • Summary table — mean, standard deviation, deciles, and range derived from the samples.
  • Confidence interval card — reflects the parsed bounds and interpretation.
  • Distribution plot (DistributionPlot) — density estimate of the samples with optional percentile markers.

Use the dropdown in the top-right of a distribution cell to switch the interpretation; the panel updates immediately. The “Settings” controls inside the plot let you toggle percentile markers or adjust the confidence level overlay for visual exploration.

Using the Flow Diagram

The Flow Diagram visualises dependencies between cells. Open it via the toolbar icon (the dotted graph). While active, the spreadsheet is dimmed and the overlay focuses on the graph.

  • Nodes display the cell address, current value, type, and formula where applicable.
  • Uncertain values reveal their distribution summary (e.g., CI[a, b] or S(μ, σ²)).
  • Edges follow HyperFormula’s dependency graph, helping you trace how uncertainty flows through calculations.

Use it to answer questions such as “Which assumptions drive the variance in my output?”: follow edges backwards from a volatile node to inspect upstream intervals. Use the built-in pan/zoom controls from @xyflow/react. Press Escape or click the spreadsheet icon to return to the grid.

Formula Bar & Editing Tips

The formula bar mirrors the active cell’s formula/value and provides a larger editing surface. It routes submissions through SpreadsheetContext.submitFormula, ensuring HyperFormula re-parses the content with uncertainty support.

  • When editing an uncertainty cell, the Formula Bar shows the original notation (CI[...]) so you can tweak bounds directly.
  • Deterministic formulas behave as in traditional spreadsheets; only the operands determine whether sampling is triggered.
